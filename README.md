### 🚀 Currently building

**Stock SaaS** — *Java · Spring Boot · PostgreSQL · Docker Compose · Playwright*
A SaaS for intelligent stock management in the vape industry. Scrapes the two main distributors, matches equivalent products across suppliers, compares prices and availability, and automates purchasing decisions based on delivery dates and sales history. Backend logic with Spring Boot, persistence with PostgreSQL/JPA, services orchestrated with Docker Compose.
